# Simple Budget Tracker

## Description
Simple Budget Tracker (also referred to as Budget Manager) is a clean, easy-to-use client-side web application designed to help you track your monthly expenses against a set budget. 

## Features
* **Monthly Tracking**: Add specific months (e.g., January, February) along with a maximum budget limit for that month.
* **Expense Management**: Easily add, edit, and delete individual expenses (transactions) for any active month.
* **Visual Budget Indicator**: Features a dynamic progress bar that visually indicates your budget usage. The bar turns green (under 75%), yellow (75% to under 100%), and red (over budget) based on your total expenses.
* **Local Data Storage**: All your budget and expense data is automatically saved to your browser's `localStorage`, meaning your data persists even if you refresh or close the page.
* **Responsive Layout**: Designed with a clean, modern user interface that features a side navigation bar for months and a main panel for tracking expenses.

## Technologies Used
* **HTML5**: For the application's structure and dialog/modal elements.
* **CSS3**: For custom styling, flexbox/grid layouts, and interactive hover effects.
* **JavaScript (Vanilla)**: Handles DOM manipulation, event listeners, and data storage logic.
* **FontAwesome**: Used for the application's UI icons.
* **Google Fonts**: Uses the "Inter" font family for typography.

## Installation and Usage
Because this is a purely client-side application, no server or installation is required:
1. Clone the repository or download the files.
2. Open the `index.html` file in any modern web browser.
3. Click "Add Month" to set up a new budget, then select the month from the sidebar to start adding expenses.
